
# + FOCO - ANSIEDADE

Sistema web para organização de tarefas pessoais, gerenciamento de prioridades e gestão do tempo, utilizando a Matriz de Eisenhower e a Técnica Pomodoro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- localStorage

## Funcionalidades

- Cadastro, edição e exclusão de tarefas.
- Organização de tarefas por meio de um quadro Kanban.
- Classificação de tarefas pela Matriz de Eisenhower.
- Temporizador Pomodoro com 25 minutos de foco e 5 minutos de descanso.
- Identificação visual de prazos.
- Indicadores de tarefas.
- Armazenamento das tarefas no navegador utilizando localStorage.

## Requisitos para execução

- Node.js instalado.
- npm (instalado junto com o Node.js).

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra o terminal na pasta principal do projeto.
3. Instale as dependências:

   npm install

4. Inicie o servidor:

   npm start

5. Abra o navegador e acesse:

   http://localhost:3000

## Armazenamento dos dados

As tarefas são armazenadas localmente no navegador por meio do localStorage. Portanto, os dados permanecem salvos no mesmo navegador, mesmo após fechar e abrir novamente a aplicação.
